Profile프로필

where I conduct research in the Multimedia Security Laboratory
under the supervision of Prof. Andrew Beng Jin Teoh.

My research focuses on cross-modal face recognition, cross-modal
and multi-modal.

2025 - 2026

AI Outbound Call System with Real-Time User Intent Sensing실시간 사용자 의도 감지 기반 AI 아웃바운드 콜 시스템

PLACAR Co., Ltd.

Developed an AI-powered outbound calling system that automatically initiates calls to customers and detects user intent in real time through speech analysis.

  • Designed and implemented a real-time intent classification pipeline that senses user utterance intent (e.g., interest, rejection, callback request, inquiry) during live outbound calls.
  • Integrated STT (Speech-to-Text) and NLU (Natural Language Understanding) modules for robust spoken language understanding in noisy telephony environments.
  • Built a dynamic dialogue management engine that adapts call scripts based on detected user intent, enabling context-aware and natural conversation flow.
  • Developed sentiment and engagement scoring to assess customer receptiveness in real time, allowing the system to escalate to human agents when appropriate.
  • Engineered the full pipeline from call initiation → speech capture → intent sensing → response generation → call wrap-up logging.

고객에게 자동으로 전화를 걸고, 음성 분석을 통해 사용자의 의도를 실시간으로 감지하는 AI 아웃바운드 콜 시스템을 개발했습니다.

  • 통화 중 고객 발화의 의도(관심, 거절, 재통화 요청, 문의 등)를 인식하는 실시간 의도 분류 파이프라인을 설계하고 구현했습니다.
  • 잡음이 많은 통신 환경에서도 안정적으로 음성 언어를 이해할 수 있도록 STT(음성인식)와 NLU(자연어 이해) 모듈을 통합했습니다.
  • 감지된 의도에 따라 통화 스크립트를 조정하는 동적 대화 관리 엔진을 구축해, 맥락에 맞는 자연스러운 대화 흐름을 구현했습니다.
  • 고객의 반응도를 실시간으로 평가하는 감정 및 참여도 스코어링을 개발해, 필요한 시점에 상담원에게 전환되도록 했습니다.
  • 통화 발신 → 음성 수집 → 의도 감지 → 응답 생성 → 통화 종료 로깅까지 전체 파이프라인을 설계했습니다.
2025 - 2026

AI Voice Cloning — Zero-Shot / Few-Shot Speaker Voice Cloning SystemAI 보이스 클로닝 — Zero-Shot / Few-Shot 화자 음성 복제 시스템

PLACAR Co., Ltd.

Developed an AI voice cloning system that reproduces a target speaker's timbre, intonation, and speaking style with no fine-tuning or with only a minimal number of speech samples, leveraging pre-trained generative models.

  • Zero-shot voice cloning: Implemented a pipeline that instantly clones a speaker's voice from a single 3–10 second reference utterance without any fine-tuning.
  • Few-shot voice cloning: Further improved cloning quality through lightweight speaker adaptation using a few minutes of speech samples.
  • Designed a speaker encoder architecture for extracting speaker embeddings that generalize to unseen speakers in open-set scenarios.
  • Applied prosody transfer, pitch/duration modeling, and in-context learning-based style conditioning to enhance naturalness of synthesized speech.

  • Built an automated evaluation module for quantitative assessment of
    speaker similarity and naturalness (MOS) of cloned voices.

  • Integrated with the AI outbound call system and deployed as a
    personalized AI voice agent that responds in a specific agent's voice in production.

사전 학습된 생성 모델을 활용해, 별도의 파인튜닝 없이 또는 극소량의 음성 샘플만으로 대상 화자의 음색과 억양, 말투를 재현하는 AI 음성 복제 시스템을 개발했습니다.

  • Zero-shot 음성 복제: 3~10초 분량의 참조 발화 하나만으로, 파인튜닝 없이 즉시 화자의 목소리를 복제하는 파이프라인을 구현했습니다.
  • Few-shot 음성 복제: 수 분 분량의 음성 샘플을 이용한 경량 화자 적응으로 복제 품질을 한층 개선했습니다.
  • 학습에 사용되지 않은 화자에게도 일반화되는 화자 임베딩을 추출하는 화자 인코더 구조를 설계했습니다.
  • 합성 음성의 자연스러움을 높이기 위해 운율 전이, 피치/길이 모델링, in-context learning 기반 스타일 조건화를 적용했습니다.

  • 복제된 음성의 화자 유사도와 자연성(MOS)을
    정량적으로 평가하는 자동 평가 모듈을 구축했습니다.

  • AI 아웃바운드 콜 시스템과 통합하여, 특정 상담원의 목소리로 응대하는
    개인화 AI 음성 에이전트로 실제 서비스에 배포했습니다.
